Kmom01

Det var roligt att komma igång med HTML igen eftersom det är det första språk jag kom i kontakt med redan som 13-åring. Jag började med att skapa en enkel webbplats med tre sidor. Sidornas struktur byggdes upp med HTML och CSS ändrar färg, placering och utseende.

Jag har både lärt mig och repeterat olika HTML-element såsom header, nav och main.

Jag har också lärt mig att använda CSS för att styla min webbplats, vilket var ett relativt nytt koncept för mig.

Jag fick också prova JavaScript för att automatiskt visa aktuellt årtal i footern. Det var helt nytt för mig och medförde att jag skrev kod i fel språk, vilket ledde till en 404-sida.

Jag stötte på några problem under arbetet. Först behövde jag installera Node.js och få npm att fungera i Git Bash. Jag hade också problem med CSS-filerna och råkade lägga HTML-kod i en JavaScript-fil.

Det här kursmomentet har gett mig en bättre förståelse för hur HTML, CSS och JavaScript samverkar.

Kmom02 – v2.0.0

Under kmom02 har jag arbetat med responsiv webbdesign. Jag har lärt mig hur CSS Grid och Flexbox kan användas för att skapa layouter som anpassar sig efter skärmens storlek.

Jag har gjort webbplatsens header responsiv med en hamburgermeny som visas på mindre skärmar. Jag har också anpassat footern så att kolumnerna staplas på mobilen.

På sidan report.html har jag använt en layout med två kolumner. På about.html har jag skapat tre kolumner med huvudinnehållet i mitten. Med hjälp av media queries visas huvudinnehållet överst när skärmen är smal.

Jag har även arbetat med JavaScript i Lab 02 och tränat på villkorssatser som if, else if, else och switch. Jag fick 18 av 21 poäng på laborationen.

Det mest lärorika var att testa webbplatsen i olika skärmbredder och se hur layouten förändrades. Jag har också fått mer erfarenhet av att felsöka med hjälp av ESLint och kursens kontrollverktyg.
